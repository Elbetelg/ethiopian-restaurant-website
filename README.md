# Ethiopian Restaurant Website
A responsive, multi-page website designed to showcase traditional Ethiopian cuisine with a focus on modern UI/UX and accessibility.

## 🚀 Live Demo
https://elbetelg.github.io/ethiopian-restaurant-website/

## ✨ Features
- **Responsive Design:** Fully functional on mobile, tablet, and desktop.
- **Accessibility:** High-contrast colors and ARIA labels for screen readers.
- **Interactive Menu:** Categorized food items with descriptions.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling and Flexbox/Grid layouts.
- **JavaScript:** Dynamic navigation and interactive elements.
